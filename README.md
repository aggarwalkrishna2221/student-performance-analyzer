# student-performance-analyzer
A Python-based program that analyzes student marks, calculates averages, assigns grades, and handles invalid inputs.
# Student Performance Analyzer

This is a beginner-level Python project created as part of my learning journey in Python programming.

## Features
- Accepts marks for multiple subjects
- Handles invalid inputs using try/except
- Calculates total and average marks
- Assigns grades based on performance

## Concepts Used
- Variables and expressions
- Loops (for/while)
- Conditional statements
- Functions
- Error handling

## How to Run
1. Clone the repository
2. Run the Python file using:
   python student_performance_analyzer.py
